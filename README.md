# Industrial Energy Consumption & Cost Optimization

## Overview
This project analyzes industrial energy consumption, production output, and operational costs across multiple machines to identify efficiency improvement opportunities.

## Tools
- Microsoft Excel
- Pivot Tables
- Data Visualization

## Objectives
- Compare machine performance
- Evaluate energy efficiency
- Analyze operational costs
- Identify optimization opportunities

## Results
- Compared energy consumption across machines
- Evaluated efficiency using Units/kWh
- Visualized production and cost trends
- Generated insights for process optimization
